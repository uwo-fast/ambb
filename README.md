# ambb

Additive Manufacture Breakout Boards are a 3D printable design to convert surface-mounted ICs to DIP for easy prototyping.

> **Corresponding Publication**:
>
> [_Overcoming Chip Shortages: Low-Cost Open-Source Parametric 3-D Printable Solderless SOIC to DIP Breakout Adapters_](https://doi.org/10.3390/inventions8020061)

## Features

- Open-source and parametric design
- Compatible with RepRap-class FFF-based 3D printers
- Enables use of surface-mounted ICs with breadboards and perfboards
- Color-coding capabilities for organization

## Usage

1. Print the design using your preferred 3D printing settings.
2. Assemble the breakout board with header pins and your desired IC.
3. Use with your favorite prototyping platform.
