# ambb

Additive Manufacture Breakout Boards are a 3D printable design to convert surface-mounted ICs to DIP for easy prototyping.

## Features

- Open-source and parametric design
- Compatible with RepRap-class FFF-based 3D printers
- Enables use of surface-mounted ICs with breadboards and perfboards
- Color-coding capabilities for organization
